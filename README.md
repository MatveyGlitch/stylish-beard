# Стильный бородач

Адаптивный веб-сайт барбершопа **«Стильный бородач»**, разработанный в рамках лабораторной работы №4 по дисциплине **«Web-программирование»**.

**Тема:** «Адаптивная вёрстка, PWA и методология БЭМ»

Проект представляет собой многостраничное веб-приложение с каталогом услуг, корзиной, выбором мастера и локальным оформлением плана визита. Сайт адаптирован для разных устройств и поддерживает установку в качестве Progressive Web App (PWA).

---

### 💈 Реализованные страницы

| Страница | Описание |
|---|---|
| `index.html` | Главная страница: категории услуг, отзывы, популярные процедуры, специальное предложение с таймером и форма обратной связи |
| `catalog.html` | Каталог услуг с фильтрацией по категориям и добавлением процедур в корзину |

| `cart.html` | Просмотр и удаление выбранных услуг, расчёт общей стоимости и времени визита |
| `booking.html` | Выбор мастера, даты и времени, проверка данных и сохранение плана визита |
| `team.html` | Карточки трёх мастеров с описанием специализации и переходом к записи |
| `contacts.html` | Контактная информация и график работы барбершопа |
| `coming-soon.html` | Анонс будущего раздела со средствами для ухода за волосами и бородой |

### ✨ Дополнительные возможности

- Адаптивная вёрстка для компьютеров, планшетов и смартфонов.
- Использование методологии БЭМ при именовании CSS-классов.
- Интерактивный слайдер категорий и модальные окна отзывов.
- Проверка формы обратной связи без отправки данных на сервер.
- Предотвращение дублирования услуг и пересечения процедур в корзине.
- Выбор доступного времени с учётом продолжительности услуг и часов работы с 10:00 до 21:00.
- Сохранение корзины и планов визита в локальном хранилище браузера.
- Установка сайта в качестве PWA и доступ к сохранённым ресурсам без интернета.

### 🛠 Используемые технологии

- **HTML5** — структура и семантическая разметка веб-страниц.
- **CSS3** — оформление, Flexbox, Grid, адаптивная вёрстка и визуальные эффекты.
- **JavaScript** — интерактивность, каталог, корзина, формы и запись.
- **БЭМ** — организация именования классов компонентов интерфейса.
- **Web App Manifest** — параметры и иконки устанавливаемого приложения.
- **Service Worker** — кеширование ресурсов и офлайн-работа.
- **LocalStorage и SessionStorage** — локальное хранение данных пользователя.

Проект реализован без серверной базы данных и сторонних JavaScript-фреймворков.

### 🚀 Локальный запуск

1. Открыть папку проекта в **PhpStorm**.
2. Запустить `index.html` через локальный веб-сервер PhpStorm или разместить проект в `htdocs` и запустить **Apache** через XAMPP.
3. Открыть сайт в браузере по локальному HTTP-адресу, например `http://localhost:63342/Barbershop/index.html` (адрес и порт могут отличаться).
4. Для проверки PWA открыть сайт в **Microsoft Edge** или другом браузере с поддержкой установки веб-приложений.

Для работы Service Worker сайт необходимо открывать через **`localhost` или HTTPS**, а не через `file://`.

### 📱 Progressive Web App (PWA)

Приложение поддерживает установку на устройство, запуск в отдельном окне и кеширование страниц, стилей, скриптов и изображений для офлайн-доступа.

Установка в **Microsoft Edge** и работа без подключения к интернету проверены. После изменения кешируемых файлов необходимо обновлять версию кеша в `sw.js`, чтобы установленное приложение получало новую версию ресурсов.

### 📝 Особенности проекта

Запись носит **демонстрационный характер**: выбранный план визита сохраняется в браузере, но не отправляется в барбершоп и не создаёт реальное бронирование. Форма обратной связи также не отправляет сообщения на сервер.

Контактные данные и профили мастеров используются в учебных целях. Фотографии взяты из стоковых источников; сведения об изображениях и лицензиях приведены в `docs/image-sources.md`.
